# Операторы и выражения в Python

## Введение

**Выражение** (expression) — это комбинация значений, переменных, операторов и вызовов функций, которую Python вычисляет в одно значение. **Оператор** (operator) — это символ или ключевое слово, выполняющее операцию над одним или несколькими **операндами**.

```python
2 + 3 * 4        # выражение -> 14
x = 5            # инструкция (присваивание), а не выражение
```

**Выражение и инструкция:**

|**Признак**|**Выражение**|**Инструкция (statement)**|
|---|---|---|
|**Даёт**|Значение|Действие (без значения)|
|**Примеры**|`1 + 2`, `len(s)`, `a if b else c`|`x = 1`, `if`, `for`, `import`, `del`|
|**В REPL**|Результат выводится|Ничего не выводится|

**Типы операторов по числу операндов:**

- **Унарные** — один операнд: `-x`, `not x`, `~x`.
- **Бинарные** — два операнда: `a + b`, `a and b`.
- **Тернарный** — три операнда: `a if cond else b`.

## Арифметические операторы

|**Оператор**|**Название**|**Пример**|**Результат**|
|---|---|---|---|
|`+`|Сложение|`7 + 2`|`9`|
|`-`|Вычитание|`7 - 2`|`5`|
|`*`|Умножение|`7 * 2`|`14`|
|`/`|Истинное деление|`7 / 2`|`3.5`|
|`//`|Целочисленное деление|`7 // 2`|`3`|
|`%`|Остаток от деления|`7 % 2`|`1`|
|`**`|Возведение в степень|`7 ** 2`|`49`|

**Ключевые моменты:**

- `/` **всегда** возвращает `float`, даже для `6 / 2` -> `3.0`.
- `//` округляет в сторону **минус бесконечности** (floor), а не к нулю.
- Знак результата `%` **совпадает со знаком делителя**.
- Всегда выполняется равенство `a == (a // b) * b + a % b`.

```python
-7 // 2     # -4  (floor, а не -3)
-7 % 2      # 1   (знак делителя)
7 % -2      # -1
divmod(7, 2)   # (3, 1) — частное и остаток сразу
pow(2, 10)     # 1024
pow(2, 10, 7)  # 2 — (2**10) % 7, эффективное возведение по модулю
```

**Унарные операторы:**

```python
+x      # унарный плюс
-x      # смена знака
```

**Дополнительно:**

- `**` правоассоциативен: `2 ** 3 ** 2` = `2 ** 9` = `512`.
- `-2 ** 2` = `-4`, так как `**` приоритетнее унарного минуса.
- `ZeroDivisionError` возникает при `/`, `//` и `%`, если делитель равен `0`.
- `+` и `*` работают и с последовательностями: `"ab" + "cd"`, `"ab" * 3`, `[1] * 3`.

### Точность чисел с плавающей точкой

Числа `float` хранятся в двоичном виде, поэтому некоторые десятичные дроби не могут быть представлены точно.

```python
0.1 + 0.2            # 0.30000000000000004
0.1 + 0.2 == 0.3     # False
```

```python
import math
math.isclose(0.1 + 0.2, 0.3)    # True

from decimal import Decimal
Decimal("0.1") + Decimal("0.2")  # Decimal('0.3')
```

- Никогда не сравнивайте `float` через `==`; используйте `math.isclose()`.
- Для денежных расчётов используйте `decimal.Decimal`.

## Операторы сравнения

Операторы сравнения возвращают `bool` (`True` / `False`).

|**Оператор**|**Значение**|**Пример**|
|---|---|---|
|`==`|Равно|`3 == 3.0` -> `True`|
|`!=`|Не равно|`3 != 4` -> `True`|
|`>`|Больше|`5 > 2`|
|`<`|Меньше|`2 < 5`|
|`>=`|Больше или равно|`5 >= 5`|
|`<=`|Меньше или равно|`4 <= 5`|

### Цепочки сравнений

Python позволяет записывать сравнения как в математике.

```python
x = 5
1 < x < 10          # True  (то же, что 1 < x and x < 10)
1 < x < 3 < 100     # False
a == b == c         # все три равны
```

- Каждый операнд вычисляется **один раз**.
- Вычисление прекращается на первом `False` (короткое замыкание).

### Сравнение разных типов

```python
1 == 1.0          # True
1 == "1"          # False
1 < "a"           # TypeError (нет порядка между int и str)
"apple" < "banana"   # True (лексикографически)
[1, 2] < [1, 3]      # True (поэлементно)
(1, 2) == (1, 2)     # True
```

## Логические операторы

|**Оператор**|**Значение**|**Пример**|
|---|---|---|
|`and`|`True`, если **оба** истинны|`a > 0 and b > 0`|
|`or`|`True`, если **хотя бы один** истинен|`a > 0 or b > 0`|
|`not`|Инвертирует логическое значение|`not a`|

**Таблица истинности:**

|`a`|`b`|`a and b`|`a or b`|`not a`|
|---|---|---|---|---|
|`True`|`True`|`True`|`True`|`False`|
|`True`|`False`|`False`|`True`|`False`|
|`False`|`True`|`False`|`True`|`True`|
|`False`|`False`|`False`|`False`|`True`|

### Истинные и ложные значения (Truthy / Falsy)

**Ложные** (в логическом контексте равны `False`):

- `False`, `None`
- Ноль: `0`, `0.0`, `0j`
- Пустые коллекции: `""`, `[]`, `()`, `{}`, `set()`, `range(0)`

**Всё остальное — истинное.**

```python
bool(0)        # False
bool("")       # False
bool([0])      # True  (непустой список)
bool("False")  # True  (непустая строка)
```

### Короткое замыкание (Short-Circuit)

`and` / `or` прекращают вычисление, как только результат становится известен, и **возвращают один из операндов**, а не обязательно `bool`.

- `a and b` -> возвращает `a`, если `a` ложно, иначе `b`.
- `a or b` -> возвращает `a`, если `a` истинно, иначе `b`.

```python
0 and 5          # 0
3 and 5          # 5
0 or 5           # 5
3 or 5           # 3
"" or "default"  # "default"
not 0            # True  (`not` всегда возвращает bool)
```

**Типичное применение — безопасный доступ и значения по умолчанию:**

```python
user and user.name          # избегаем AttributeError, если user равен None
name = input_name or "Guest"

if x != 0 and 10 / x > 2:   # вторая часть не вычисляется при x == 0
    ...
```

## Операторы присваивания

|**Оператор**|**Эквивалент**|**Пример (x = 10)**|**Результат**|
|---|---|---|---|
|`=`|—|`x = 10`|`10`|
|`+=`|`x = x + n`|`x += 3`|`13`|
|`-=`|`x = x - n`|`x -= 3`|`7`|
|`*=`|`x = x * n`|`x *= 3`|`30`|
|`/=`|`x = x / n`|`x /= 4`|`2.5`|
|`//=`|`x = x // n`|`x //= 3`|`3`|
|`%=`|`x = x % n`|`x %= 3`|`1`|
|`**=`|`x = x ** n`|`x **= 2`|`100`|
|`&=` `\|=` `^=`|побитовые варианты|`x &= 6`|—|
|`<<=` `>>=`|варианты со сдвигом|`x <<= 1`|`20`|

**Поведение для изменяемых и неизменяемых типов:**

```python
a = [1, 2]
b = a
a += [3]         # на месте: изменяется тот же список
print(b)         # [1, 2, 3]

a = [1, 2]
b = a
a = a + [3]      # создаётся НОВЫЙ список
print(b)         # [1, 2]

n = 5
n += 1           # int неизменяем: n теперь указывает на новый объект
```

### Оператор «морж» `:=` (Python 3.8+)

**Выражение присваивания**: присваивает значение и возвращает его внутри более крупного выражения.

```python
if (n := len(items)) > 10:
    print(f"Too many: {n}")

while (line := input("> ")) != "quit":
    print(line)

squares = [y for x in data if (y := x * x) > 10]
```

- Скобки обычно обязательны.
- Используйте умеренно; читаемость важнее.

## Побитовые операторы

Работают с **двоичным представлением** целых чисел.

|**Оператор**|**Название**|**Пример** (`a=6` `0110`, `b=3` `0011`)|**Результат**|
|---|---|---|---|
|`&`|И (AND)|`a & b`|`2` (`0010`)|
|`\|`|ИЛИ (OR)|`a \| b`|`7` (`0111`)|
|`^`|XOR|`a ^ b`|`5` (`0101`)|
|`~`|НЕ (инверсия)|`~a`|`-7`|
|`<<`|Сдвиг влево|`a << 1`|`12`|
|`>>`|Сдвиг вправо|`a >> 1`|`3`|

**Ключевые моменты:**

- `~x` равно `-(x + 1)` (дополнительный код).
- `x << n` — это `x * 2**n`; `x >> n` — это `x // 2**n`.
- Целые числа в Python имеют произвольный размер, поэтому переполнения нет.

```python
bin(10)          # '0b1010'
int("1010", 2)   # 10
0b1010           # двоичный литерал
0xFF             # шестнадцатеричный литерал -> 255
0o17             # восьмеричный литерал -> 15
```

**Типичное применение — флаги и приёмы:**

```python
x & 1 == 0          # проверка на чётность  (осторожно: используйте (x & 1) == 0)
x & (1 << k)        # проверить бит k
x | (1 << k)        # установить бит k
x & ~(1 << k)       # сбросить бит k
x ^ (1 << k)        # инвертировать бит k
a ^= b; b ^= a; a ^= b   # обмен через XOR (лучше использовать a, b = b, a)
```

## Операторы идентичности

|**Оператор**|**Значение**|
|---|---|
|`is`|Оба имени ссылаются на **один и тот же объект**|
|`is not`|Имена ссылаются на **разные объекты**|

```python
a = [1, 2]
b = a
c = [1, 2]

a is b       # True   (один объект)
a is c       # False  (разные объекты)
a == c       # True   (равные значения)
```

- `is` сравнивает `id()`, `==` сравнивает значения.
- **Для `None`, `True`, `False` всегда используйте `is`:** `if x is None`.
- **Не** используйте `is` для чисел и строк: кеширование малых int и строк — деталь реализации.

```python
a = 256; b = 256
a is b        # True  (кешируется в CPython)
a = 1000; b = 1000
a is b        # может быть False
```

## Операторы принадлежности

|**Оператор**|**Значение**|
|---|---|
|`in`|Значение найдено в контейнере|
|`not in`|Значение **не** найдено|

```python
3 in [1, 2, 3]           # True
"a" in "banana"          # True (проверка подстроки)
"ban" in "banana"        # True
"x" not in "banana"      # True
"key" in {"key": 1}      # True (проверяются КЛЮЧИ)
1 in {"key": 1}          # False (это не ключ)
(1, 2) in [(1, 2), (3,)] # True
```

**Производительность:**

|**Контейнер**|**Сложность `in`**|
|---|---|
|`list`, `tuple`|O(n)|
|`set`, `dict`|O(1) в среднем|
|`str` (подстрока)|O(n·m) в худшем случае|

Для частых проверок принадлежности используйте `set`.

## Приоритет и ассоциативность операторов

**Приоритет** определяет, какой оператор вычисляется первым; **ассоциативность** определяет порядок среди операторов одного приоритета.

**От высшего приоритета к низшему:**

|**Уровень**|**Операторы**|**Ассоциативность**|
|---|---|---|
|1|`( )` скобки, `[ ]`, `{ }`, вызов `f()`, атрибут `x.y`|—|
|2|`**`|правая|
|3|`+x`, `-x`, `~x` (унарные)|правая|
|4|`*`, `/`, `//`, `%`, `@`|левая|
|5|`+`, `-`|левая|
|6|`<<`, `>>`|левая|
|7|`&`|левая|
|8|`^`|левая|
|9|`\|`|левая|
|10|`==`, `!=`, `<`, `<=`, `>`, `>=`, `is`, `is not`, `in`, `not in`|цепочки|
|11|`not`|правая|
|12|`and`|левая|
|13|`or`|левая|
|14|`if ... else` (тернарный)|правая|
|15|`lambda`|—|
|16|`:=`|—|

```python
2 + 3 * 4          # 14  (* раньше +)
(2 + 3) * 4        # 20
2 ** 3 ** 2        # 512 (правая ассоциативность)
-3 ** 2            # -9
not a == b         # not (a == b)
a or b and c       # a or (b and c)
10 - 5 - 2         # 3   (левая ассоциативность: (10 - 5) - 2)
```

**Совет:** если есть сомнения, добавляйте скобки — они ничего не стоят и улучшают читаемость.

## Условное выражение (тернарный оператор)

```python
value = a if condition else b
```

- Сначала вычисляется `condition`; затем только одно из `a` / `b`.
- Это **выражение**, поэтому его можно использовать внутри других выражений.

```python
status = "adult" if age >= 18 else "minor"
abs_x = x if x >= 0 else -x
print("even" if n % 2 == 0 else "odd")

# Вложенное (избегайте глубокой вложенности)
grade = "A" if score >= 90 else "B" if score >= 80 else "C"
```

## Прочие операторы

### Матричное умножение `@`

```python
# используется в основном с массивами NumPy
A @ B
```

### Операторы распаковки `*` и `**`

```python
a = [1, 2]
b = [3, 4]
[*a, *b]                 # [1, 2, 3, 4]

d1 = {"x": 1}
d2 = {"y": 2}
{**d1, **d2}             # {'x': 1, 'y': 2}

print(*a)                # print(1, 2)
```

### Слияние словарей `|` (Python 3.9+)

```python
{"a": 1} | {"b": 2}      # {'a': 1, 'b': 2}
d1 |= d2                 # обновление на месте
```

### Индексация, срезы, вызов

```python
s[0]          # индексация
s[1:4]        # срез
s[::-1]       # в обратном порядке
f(x)          # вызов
obj.attr      # доступ к атрибуту
```

## Преобразование типов в выражениях

**Неявное (числовое повышение):** `int` -> `float` -> `complex`.

```python
1 + 2.5        # 3.5 (float)
True + 1       # 2   (bool — подкласс int)
```

**Явное преобразование:**

```python
int("42")        # 42
int(3.9)         # 3  (отбрасывает дробную часть в сторону нуля)
float("3.14")    # 3.14
str(10)          # "10"
bool("")         # False
round(3.5)       # 4
round(2.5)       # 2  (банковское округление: к чётному)
```

- Неявного преобразования между `str` и числами **нет**: `"5" + 5` -> `TypeError`.

## Перегрузка операторов (кратко)

Операторы связаны со **специальными (dunder) методами**, поэтому пользовательские классы могут задавать собственное поведение.

|**Оператор**|**Метод**|
|---|---|
|`+`|`__add__`|
|`-`|`__sub__`|
|`*`|`__mul__`|
|`/`|`__truediv__`|
|`==`|`__eq__`|
|`<`|`__lt__`|
|`len(x)`|`__len__`|
|`x[i]`|`__getitem__`|
|`in`|`__contains__`|

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

v = Vector(1, 2) + Vector(3, 4)   # вызывается __add__
```

## Типичные ошибки

|**Ошибка**|**Проблема / Исправление**|
|---|---|
|`if x = 5:`|`SyntaxError`; для сравнения используйте `==`|
|`0.1 + 0.2 == 0.3`|Погрешность float; используйте `math.isclose()`|
|`x is 1000`|Ненадёжно; используйте `==`|
|`if x == None:`|Работает, но лучше `if x is None:`|
|`a == b or c`|Означает `(a == b) or c`; пишите `a == b or a == c` или `a in (b, c)`|
|`7 / 2` в ожидании `3`|`/` — истинное деление; используйте `//`|
|`-7 // 2` в ожидании `-3`|Целочисленное деление даёт `-4`|
|`"5" + 5`|`TypeError`; преобразуйте явно|
|`a += [x]` и `a = a + [x]`|На месте и новый объект; влияет на псевдонимы|
|`not x == y`|Разбирается как `not (x == y)`; лучше `x != y`|

## Итоги

- **Выражение** даёт значение; **инструкция** выполняет действие.
- **Арифметические:** `+ - * / // % **`; `/` всегда возвращает `float`, `//` округляет вниз, знак `%` следует за делителем.
- **Сравнения:** `== != < > <= >=`; поддерживают **цепочки** (`1 < x < 10`).
- **Логические:** `and`, `or`, `not`; работают с коротким замыканием и возвращают **операнд**, а не обязательно `bool`.
- **Присваивания:** `=`, составные (`+=`, ...) и «морж» `:=`.
- **Побитовые:** `& | ^ ~ << >>` работают с битами целых чисел.
- **Идентичность:** `is` / `is not` сравнивают объекты; **принадлежность:** `in` / `not in` ищут в контейнерах.
- **Приоритет:** `**` > унарные > `* / // %` > `+ -` > сдвиги > побитовые > сравнения > `not` > `and` > `or` > тернарный; при сомнениях используйте скобки.
- **Тернарный оператор:** `a if cond else b`.
- Операторы связаны с dunder-методами, что позволяет делать **перегрузку операторов**.
