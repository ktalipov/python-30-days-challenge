# Типы данных и приведение типов в Python

## Типы данных

**Тип данных** в Python — это характеристика объекта, определяющая, какие значения он может хранить и какие операции над ним допустимы. Тип принадлежит объекту, а не переменной, и определяется во время выполнения (`type(x)`).

Основные встроенные типы: `int`, `float`, `bool`, `str`, `list`, `tuple`, `dict`, `set`, `NoneType`.

### Основные встроенные типы данных Python:

|**Категория**|**Типы**|**Примеры**|
|---|---|---|
|**Числовые**|`int`, `float`, `complex`|`10`, `3.14`, `2+3j`|
|**Логический**|`bool`|`True`, `False`|
|**Строковый**|`str`|`"text"`|
|**Последовательности**|`list`, `tuple`, `range`|`[1, 2]`, `(1, 2)`, `range(5)`|
|**Отображения**|`dict`|`{"a": 1}`|
|**Множества**|`set`, `frozenset`|`{1, 2, 3}`|
|**Двоичные**|`bytes`, `bytearray`, `memoryview`|`b"abc"`|
|**Отсутствие значения**|`NoneType`|`None`|

### Классификация по изменяемости:

- **Неизменяемые (immutable):** `int`, `float`, `complex`, `bool`, `str`, `tuple`, `frozenset`, `bytes`, `None`
    
- **Изменяемые (mutable):** `list`, `dict`, `set`, `bytearray`
    

### Классификация по структуре:

- **Скалярные (простые):** `int`, `float`, `bool`, `complex`, `None`
    
- **Коллекции (составные):** `str`, `list`, `tuple`, `dict`, `set`, `range`
    

**Проверка типа:** `type(x)` или `isinstance(x, int)`

## Приведение типов

**Приведение типов** (type conversion, type casting) — это преобразование значения одного типа данных в другой. При преобразовании создаётся **новый объект**, исходный объект не изменяется.

### 1. Неявное приведение

Python преобразует типы автоматически, когда это безопасно и нет потери информации (обычно к более «широкому» типу).

```python
1 + 2.5      # 3.5     (int -> float)
True + 1     # 2       (bool -> int)
2 + 3j       # (2+3j)  (int -> complex)
```

Python — язык со строгой типизацией, поэтому несовместимые типы неявно **не** преобразуются:

```python
"5" + 5      # TypeError
```

### 2. Явное приведение

Программист сам вызывает функцию-конструктор нужного типа.

|**Функция**|**Преобразует в**|**Пример**|**Результат**|
|---|---|---|---|
|`int()`|целое число|`int("42")`, `int(3.9)`|`42`, `3`|
|`float()`|число с плавающей точкой|`float("3.14")`, `float(5)`|`3.14`, `5.0`|
|`str()`|строку|`str(10)`, `str([1, 2])`|`"10"`, `"[1, 2]"`|
|`bool()`|логическое значение|`bool(0)`, `bool("a")`|`False`, `True`|
|`list()`|список|`list("abc")`, `list((1, 2))`|`['a', 'b', 'c']`, `[1, 2]`|
|`tuple()`|кортеж|`tuple([1, 2])`|`(1, 2)`|
|`set()`|множество|`set([1, 1, 2])`|`{1, 2}`|
|`dict()`|словарь|`dict([("a", 1)])`|`{'a': 1}`|

### Важные детали

- `int(3.9)` **отбрасывает** дробную часть (даёт `3`), а не округляет. Для округления используется `round()`.
- `int("3.5")` вызывает `ValueError`; нужно преобразовывать через float: `int(float("3.5"))`.
- `set()` удаляет дубликаты и не сохраняет исходный порядок.
- `str(x)` работает для любого объекта, а `int()` и `float()` только для корректных числовых значений.

### 3. Ошибки преобразования

Если значение нельзя преобразовать, возникает исключение:

```python
int("abc")    # ValueError
int(None)     # TypeError
```

Обработка через `try/except`:

```python
try:
    n = int(input("Number: "))
except ValueError:
    print("Not a number")
```

### 4. Приведение к bool (truthy и falsy)

`bool(x)` возвращает `False` для следующих значений, а для всех остальных `True`:

- `0`, `0.0`, `0j`
- `""` (пустая строка)
- `[]`, `()`, `{}`, `set()`, `range(0)`
- `None`
- `False`

```python
bool(0)        # False
bool("")       # False
bool([])       # False
bool("0")      # True  (непустая строка)
bool([0])      # True  (непустой список)
```

### 5. Типичный случай использования

`input()` всегда возвращает `str`, поэтому числа нужно преобразовывать:

```python
age = int(input("Age: "))
price = float(input("Price: "))
```

## Кратко

- Приведение типов создаёт новый объект другого типа.
- **Неявное:** выполняется автоматически для совместимых числовых типов (`int` -> `float`).
- **Явное:** выполняется функциями `int()`, `float()`, `str()`, `bool()`, `list()`, `tuple()`, `set()`, `dict()`.
- Несовместимые значения вызывают `ValueError` или `TypeError`.
- Falsy-значения: `0`, `""`, `[]`, `()`, `{}`, `set()`, `None`; всё остальное truthy.
