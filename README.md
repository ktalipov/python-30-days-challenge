# 🐍 30 Days of Python Challenge

## About the Challenge

A 30-day Python learning challenge focused on building strong programming fundamentals through daily practice, problem-solving, and hands-on projects.

The main goal is to develop practical Python skills, understand core programming concepts, and build a foundation for Data Engineering.

**Duration:** November 4 – December 3, 2026  
**Daily commitment:** 2 hours  
**Language:** Python 3  
**Focus:** Python Fundamentals, OOP, Data Processing, APIs, PostgreSQL and ETL.

### Main Goals

- Master Python fundamentals and core concepts.
- Understand functions, data structures, and OOP.
- Learn file handling and exception handling.
- Work with JSON, CSV, REST APIs, and external data.
- Practice data processing with Pandas.
- Connect Python applications to PostgreSQL.
- Build practical projects independently.
- Develop problem-solving skills.
